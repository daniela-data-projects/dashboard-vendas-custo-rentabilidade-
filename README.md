# Dashboard de Vendas, Custos e Rentabilidade | Power BI

## 🎯 Sobre o projeto

Este projeto foi desenvolvido durante meus estudos em análise de dados, utilizando o Power BI para explorar informações de vendas, custos, margem de lucro e indicadores de desempenho.

A proposta foi transformar uma base de dados em visualizações que facilitassem a compreensão dos resultados, permitindo analisar diferentes indicadores e observar o desempenho por categorias, mercados e outras dimensões disponíveis nos dados.

Este trabalho também fez parte do meu processo de aprendizado, permitindo colocar em prática conceitos de modelagem de dados, visualização e construção de dashboards analíticos.

## 🗂️ Modelo de dados

O projeto utiliza tabelas de clientes, pedidos, produtos e vendas, conectadas por meio de relacionamentos. Essa estrutura permite integrar informações de diferentes tabelas e utilizá-las nas análises e visualizações do dashboard.

## 🔎 Principais análises

* 📊 Análise de indicadores de vendas e custos.
* 💰 Acompanhamento da margem de lucro.
* 🌎 Comparação de resultados por categorias e mercados.
* 🎯 Visualização de indicadores-chave de desempenho (KPIs).
* 📉 Análise de dados por meio de gráficos e indicadores visuais.

## 📚 Aprendizados e desenvolvimento do projeto

Durante o desenvolvimento deste projeto, tive a oportunidade de explorar diferentes recursos do Power BI e compreender melhor como os dados podem ser organizados e transformados em informações úteis para a análise de resultados.

Uma das etapas importantes foi trabalhar com a estrutura dos dados e entender como as tabelas de clientes, pedidos, produtos e vendas se relacionam. A construção e a análise desses relacionamentos ajudaram a ampliar minha compreensão sobre a modelagem de dados e sua importância para que as informações sejam apresentadas de forma consistente.

Também trabalhei na construção de visualizações para acompanhar indicadores de vendas, custos e margem de lucro, explorando diferentes tipos de gráficos para facilitar a leitura e a interpretação dos resultados. A organização dos elementos visuais foi outra parte importante, buscando deixar o dashboard mais claro, intuitivo e funcional.

Ao longo desse processo, pude desenvolver uma visão mais ampla sobre a construção de dashboards analíticos, desde a organização das informações até a apresentação dos resultados. Também compreendi melhor como os indicadores podem ajudar a identificar padrões e facilitar a análise do desempenho.

Este projeto representa mais uma etapa da minha evolução na área de análise de dados. Foi uma oportunidade de colocar conhecimentos em prática, conhecer melhor os recursos do Power BI e fortalecer minha capacidade de transformar dados em informações visuais que apoiem a tomada de decisão.
